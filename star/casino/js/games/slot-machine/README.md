# Slot Machine

## État

Playable alpha — repaired and isolated.

## Règle

- Grille : 5 rouleaux × 3 lignes.
- 5 lignes actives : haut, milieu, bas, deux diagonales.
- Gains de gauche à droite à partir de 3 symboles identiques.
- Symboles pondérés par rareté.

## Équilibrage actuel

- RTP cible alpha : environ 90%.
- Les lignes secondaires ont un multiplicateur réduit.
- Les symboles rares paient plus mais sortent beaucoup moins.

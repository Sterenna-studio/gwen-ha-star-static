# Whack-A-Mole

## État

Playable alpha.

## Règle

- Durée : 30 secondes.
- Le joueur frappe les entités qui sortent des trous.
- Les bombes retirent des points et cassent le combo.
- Le score final convertit la mise en gain.

## Équilibrage actuel

- Ratio gain : `mise × score / 12`.
- Difficulté progressive : nombre d'entités actives augmente pendant la partie.
- Types pondérés : normal, fast, golden, bomb.

## À améliorer

- Countdown visuel plus propre.
- Résultat de fin plus détaillé.
- Stats : précision, meilleur score, combo max.

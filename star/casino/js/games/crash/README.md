# Crash

## État

Playable alpha.

## Règle

- Le joueur mise des Chronicles.
- Le multiplicateur monte progressivement.
- Il faut s'éjecter avant le crash.
- Auto-eject disponible.

## Équilibrage actuel

- Courbe de crash basée sur une formule à edge alpha autour de 94%.
- Auto-eject conseillé entre x1.6 et x2.5.
- Historique local des derniers multiplicateurs.

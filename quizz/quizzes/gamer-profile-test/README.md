# Gamer Profile Test — V0.1

Prototype data-first d'un questionnaire humoristique sur les habitudes de joueur, le PC, les consoles, les périphériques et le chaos numérique.

## Intention

Le test place le joueur sur un continuum :

- **Carré** : préparé, rangé, méthodique, matériel entretenu.
- **Rond** : spontané, improvisateur, chaos fonctionnel.
- Entre les deux : la plupart des vrais joueurs.

Ce n'est pas un test psychologique ou psychométrique. Le ton doit rester léger : une réponse « Rond » ne doit jamais être présentée comme une mauvaise réponse.

## Principe éditorial à conserver

Chaque réponse contient toujours deux niveaux :

1. le **comportement concret** du joueur ;
2. une **petite phrase incarnée** que ce joueur pourrait réellement prononcer.

Exemple :

> Chaque objet a sa catégorie. Je trie régulièrement et je sais exactement ce que je transporte.  
> « Donnez-moi les ressources rares, je m'occupe de les garder. »

La petite phrase est une partie importante du concept et doit rester présente dans les futures versions.

## V0.1

- 30 questions prévues dans la source de contenu.
- 3 réponses A/B/C par question.
- A = 2 points Carré ; B = 1 ; C = 0.
- 5 axes cachés : organisation, anticipation, maintenance, hygiène numérique, setup.
- Les axes sont normalisés puis pondérés à poids égal pour le résultat global.
- Hooks prévus pour ajouter plus tard une illustration par question, par réponse ou uniquement au résultat.

## Images

Le contenu ne doit jamais dépendre d'une image pour être compris. Les futurs assets doivent renforcer la blague. Chaque question/réponse pourra recevoir une illustration simple lorsque la direction graphique sera choisie.

## État

Cette V0.1 sert d'abord de base éditoriale. La structure HTML/CSS/JS du questionnaire sera produite ensuite à partir des données, sans hardcoder le contenu dans l'interface.

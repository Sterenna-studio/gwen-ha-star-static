# Gamer Profile Test — Archive V0.2

Cette proposition éditoriale n'est plus chargée par la version jouable de **Carré ou Rond ?**.

Le test public utilise de nouveau les 30 questions originales de `questions.json`. Il conserve toutefois le calcul moderne : A vaut 0 point Rond, B vaut 1, C vaut 2, pour un score final sur 60 accompagné des pourcentages Carré/Rond et du détail par axe.

Les fichiers de ce dossier sont conservés uniquement comme archive de travail :

- `profile.json` : ancien profil d'entrée ;
- `questions-additions.json` : cinq questions retirées de la version jouable ;
- `question-patches.json` : anciens bonus contextuels, désormais inactifs ;
- `scoring.json` et `results.json` : ancien barème sur 72 points, désormais inactif.

Ils ne doivent pas être fusionnés au questionnaire actif sans une nouvelle décision éditoriale.

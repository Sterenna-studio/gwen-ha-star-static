# shared/ — Assets partagés du hub Gwen Ha Star

Ce dossier contient tous les assets visuels utilisés par les pages **racine** du site.
Il est **distinct et indépendant** de `TCG/assets/` qui appartient exclusivement au TCG.

```
shared/
├── logos/          ← Logos & identité visuelle (bzh-chronicles, bzh-pw, sterenna, favicon)
└── images/         ← Images illustratives (vaisseaux, fonds, etc.)
```

## TCG/assets/ vs shared/

| Dossier | Appartient à | Contenu |
|---|---|---|
| `shared/` | Hub global (index.html, star/, cig.html...) | Logos, images générales |
| `TCG/assets/` | TCG exclusivement | Cartes, packs, icônes TCG |
